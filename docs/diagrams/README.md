# Диаграммы (draw.io)

Файлы открываются в draw.io (https://app.diagrams.net или приложение diagrams.net): «Файл → Открыть с устройства». Внутри файла несколько страниц, они переключаются вкладками внизу окна. Экспорт в картинку: «Файл → Экспортировать как → PNG/SVG/PDF».

| Файл | Диаграмма | Откуда берётся |
|---|---|---|
| `er.drawio` | ER-диаграмма базы данных: общая схема и по странице на каждый модуль (счета и проводки, переводы, вклады, кредиты, карты, платежи, антифрод, ...) | автоматически из работающей базы PostgreSQL |
| `classes.drawio` | диаграммы классов: слои приложения (контроллеры, сервисы, модели), сервисы бизнес-логики и их зависимости, модели доступа к данным, библиотеки | автоматически из исходного кода `src/` |
| `usecases.drawio` | диаграмма вариантов использования: гость, клиент и четыре роли сотрудников | описана в `scripts/uml-drawio.js` |
| `sequence.drawio` | диаграммы последовательности: перевод клиенту банка, заявка на кредит, закрытие операционного дня | описаны в `scripts/uml-drawio.js` |

## Как перестроить

Диаграммы ER и классов можно пересоздать после любого изменения базы или кода:

```
npm run er:drawio     # ER по базе из DATABASE_URL
npm run uml:drawio    # классы, варианты использования, последовательности
```

Файлы перезаписываются. Если вы вручную поправили расположение в draw.io, сохраните файл под другим именем, иначе правки пропадут.

## Как устроена ER-диаграмма

Скрипт `scripts/er-drawio.js` читает схему так же, как это делают графические клиенты: запрашивает у PostgreSQL системное представление `information_schema` (таблицы, столбцы и типы, первичные ключи, внешние ключи) и рисует из этого файл draw.io. Ключи помечены `PK` и `FK`, связи нарисованы по внешним ключам (на стороне «многие» стоит «вилка»). На странице модуля таблицы соседних модулей показаны серым.

## Что в диаграммах нужно доработать вручную

- Автоматическая раскладка не знает, какие связи важнее. Для плаката перетащите таблицы так, чтобы пересечений было меньше, и уберите лишние поля.
- Для нотации IDEF1X (если её требует руководитель) стили таблиц и связей придётся поменять в draw.io: набор фигур «Entity Relation» есть в левой панели.
- Диаграммы вариантов использования и последовательности описаны текстом в скрипте. Подписи можно править прямо в draw.io.
