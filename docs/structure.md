# Структура проекта

Код сгруппирован не по типам файлов, а по предметным модулям: всё, что относится к одной области (например, к кредитам), лежит в одной папке. Чтобы понять или изменить область, достаточно открыть одну папку.

```
server/                    сервер
client/                    интерфейс
db/sql/                    схема базы данных (NNN_*.sql)
test/                      автотесты, по папке на модуль
tools/                     служебные скрипты
docs/                      документация
```

## Сервер: `server/`

| Что | Где |
|---|---|
| Запуск и сборка Express | `server/server.js`, `server/app.js` |
| Все маршруты API | `server/routes.js` (подключает `routes.js` каждого модуля) |
| Настройки из `.env` | `server/config/index.js` |
| База данных: пул, транзакции, миграции, начальные данные | `server/db/` |
| Общее для всех модулей | `server/shared/` (ошибки, деньги, даты, IBAN, шифрование, проверка данных, middleware: сессии, CSRF, права, обработчик ошибок) |
| Предметные модули | `server/modules/<модуль>/` |

### Модули

| Модуль | Что делает |
|---|---|
| `auth` | Вход, регистрация, выход, сессия, двухфакторная защита (TOTP), одноразовые коды, страница «Безопасность», меню по ролям |
| `clients` | Анкета клиента, проверка анкеты (KYC) |
| `accounts` | Счета и IBAN, выписки и справки, PDF-документы |
| `ledger` | Двойная запись: документы и проводки, холды, сторно |
| `cards` | Банковские карты: выпуск, лимиты, блокировка, покупки |
| `transfers` | Переводы клиентам, между своими счетами, в другие банки (клиринг) |
| `fraud` | Антифрод: оценка риска, очередь задержанных переводов |
| `payments` | Каталог платежей, шаблоны, автоплатежи, квитанции |
| `deposits` | Вклады, проценты, досрочное закрытие |
| `loans` | Кредиты: заявки, скоринг, графики платежей, просрочка, погашение, рабочее место кредитного специалиста |
| `staff` | Рабочее место операциониста: касса, входящие платежи, блокировка счетов |
| `admin` | Курсы и тарифы, пользователи и роли, отчёты, резервные копии, закрытие операционного дня |
| `rates` | Курсы валют Национального банка со спредом банка, конвертер |
| `settings` | Тарифы и лимиты в настройках системы |
| `audit` | Неизменяемый журнал аудита |
| `notifications` | Внутренние уведомления, почта и очередь писем |
| `dashboard` | Главные страницы гостя, клиента и сотрудника, информационные страницы, поиск |

### Файлы внутри модуля

Имя файла показывает его роль. Не каждый модуль содержит все виды файлов.

| Файл | Назначение |
|---|---|
| `routes.js` | Адреса API модуля и права доступа к ним |
| `<имя>.controller.js` | Обработчик HTTP: берёт данные запроса, вызывает сервис, отвечает JSON. SQL не пишет |
| `<имя>.service.js` | Бизнес-логика, транзакции, проверки. Единственное место, где принимаются решения |
| `<имя>.model.js` | SQL-запросы к таблицам. Про HTTP ничего не знает |
| прочие файлы | Расчёты и вспомогательные функции, нужные только этому модулю (например `loans/schedule.js`, `cards/luhn.js`) |

Цепочка вызовов: `routes.js` → `*.controller.js` → `*.service.js` → `*.model.js` → MySQL. Модуль может вызывать сервисы и модели другого модуля (например, любая денежная операция идёт через `ledger/ledger.service.js`), но только через их экспортируемые функции.

## Интерфейс: `client/`

| Что | Где |
|---|---|
| Оболочка приложения | `client/index.html` |
| Единственная таблица стилей | `client/css/style.css` |
| Изображения | `client/img/` |
| Общие модули | `client/js/lib/` (маршрутизатор, запросы к API, шаблоны `html`, формы, анимации, шапка и поиск) |
| Точка входа и список маршрутов | `client/js/app.js`, `client/js/routes.js` |
| Экраны модуля | `client/js/modules/<модуль>/routes.js` и `client/js/modules/<модуль>/pages/*.js` |

Модули клиента называются так же, как серверные: экраны модуля `loans` лежат в `client/js/modules/loans/pages/`, адреса их API в `server/modules/loans/routes.js`. Подробнее о страницах, формах и соглашениях: [frontend.md](frontend.md).

## Тесты: `test/`

30 тестов бизнес-логики в папках модулей: `ledger` (двойная запись), `transfers` (переводы и курсы), `loans/schedule.test.js` (графики и скоринг), `deposits` (вклады), `shared/lib.test.js` (деньги, IBAN, шифрование), `auth/totp.test.js` (коды 2FA). Общие помощники: `test/helpers.js` (создание клиентов и счетов), `test/env.js`, `test/globalSetup.js` (пересоздаёт тестовую базу). Запуск: `npm test`.

## Служебные скрипты: `tools/`

| Скрипт | Назначение |
|---|---|
| `setup.js` | Создаёт `.env` со случайными ключами |
| `build-schema.js` | Собирает `db/schema.sql` из `db/sql` |
| `train-scoring.js` | Обучает модель кредитного скоринга |
| `demo-data.js` | Демонстрационные операции после `db:seed` (`npm run db:demo`) |
| `staff-2fa.js` | Включает и выключает обязательную 2FA сотрудников |
| `er-drawio.js`, `class-diagrams.js`, `uml-drawio.js`, `uml-views.js` | Диаграммы для записки (draw.io и SVG) |
| `kursovaya/` | Сборка пояснительной записки (docx) |

## Как добавить модуль

1. Новый SQL-файл в `db/sql` (следующий номер), `npm run db:migrate`.
2. Папка `server/modules/<модуль>/` с `*.model.js`, `*.service.js`, `*.controller.js`, `routes.js`; подключить `routes.js` в `server/routes.js`.
3. Папка `client/js/modules/<модуль>/` с `routes.js` и `pages/`; подключить маршруты в `client/js/routes.js`.
4. Тесты в `test/<модуль>/`.
