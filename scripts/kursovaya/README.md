# Сборка docx для записки

- `split_tables.py вход.docx выход.docx` – разрезает таблицы по страницам: «Продолжение таблицы X.X» вверху новой страницы и повтор шапки. Разбивка считается по PDF из LibreOffice, после правок текста запускайте заново на исходном файле.
- `build_13.py шаблон.docx выход.docx` – дополнение к разделу 1.3 (бизнес-цели, видение, бизнес-правила, заинтересованные лица, описание вариантов использования). Шаблон – docx черновика записки, текст в `content_13.py`.

Нужны `python-docx`, `soffice` (LibreOffice) и `pdftotext` (poppler).
